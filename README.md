# A&S Live (com.alijamal.aslive2)

- تحميل مباشر: https://github.com/ali1990132-ctrl/ASLive-new/raw/main/A%26S_Live.apk
- التحديث الداخلي الإجباري يقرأ `version.json` من هذا الفرع (main).

## طريقة نشر تحديث
1. ارفع ملف التطبيق الجديد بنفس الاسم `A&S_Live.apk` (موقّع بنفس المفتاح).
2. ارفع `versionCode` في `version.json` لرقم أكبر من نسخة المشتركين (مثلاً 62) وغيّر `versionName`.
3. أول ما يفتح المشترك التطبيق تطلع له نافذة "تحديث جديد متوفر" ولازم يحدّث.
